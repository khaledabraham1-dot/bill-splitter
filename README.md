# Python Bill Splitter

## Description

A simple Python program that calculates the total restaurant bill, adds a 25% tip, and calculates how much each person should pay.

This project was completed as part of a Python workshop.

## Features

- Calculates the total cost of appetizers, main courses, desserts, and drinks
- Calculates a 25% tip
- Adds the tip to the total bill
- Splits the bill between 4 people
- Rounds the final amount to 2 decimal places

## Technologies

- Python 3

## Concepts Practiced

- Variables
- Numbers and arithmetic operations
- Addition and multiplication
- Division
- Assignment operators (`+=`)
- The `round()` function
- f-strings
- `print()`

## Example

The program calculates:

- Food and drinks total: 199.83
- 25% tip: 49.9575
- Total including tip: 249.7875
- Number of people: 4
- Amount per person: 62.45
